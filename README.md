# 🛡️ Aegis L7 Defense Plugin (마인크래프트 봇 방어 플러그인)

**Aegis L7**은 최첨단 기법(지도 OCR 캡챠, 3D 엔티티 캡챠, 투명 리소스팩 등)을 활용해 봇넷, 디도스(DDoS), 매크로 공격을 100% 원천 차단하는 마인크래프트 플러그인입니다.

---

## 📥 설치 방법 (Installation)
1. GitHub **[Releases]** 탭에서 가장 최신 버전의 Aegis-L7 (Latest Build).jar 파일을 다운로드합니다.
2. 서버의 plugins/ 폴더에 .jar 파일을 넣습니다.
3. 서버를 시작(또는 재시작)합니다.
4. plugins/L7DefensePlugin/config.yml 파일이 자동 생성되면 설정을 확인합니다.

---

## ⚠️ [필독] 프록시(BungeeCord / Velocity) 서버 사용 시 주의사항

**프록시 서버나 TCPShield 같은 디도스 방어망을 사용하는 메인 서버**의 경우, 플레이어의 '서버 새로고침(Ping)' 패킷이 백엔드(야생) 서버에 도달하지 않습니다.
따라서 아래 기능이 켜져 있으면 **정상적인 유저도 봇으로 오해받아 영구 차단(Ping 기록 없음 등)** 될 수 있습니다!

**해결 방법 (config.yml 수정):**
\\\yaml
# 아래 3가지 모듈은 반드시 false로 설정하세요! (v1.0.0 부터 기본값 false 적용)
ping-before-join:
  enabled: false    # Ping 기록 없음 에러 방지

anti-vpn:
  enabled: false    # 제한된 국가/데이터센터 차단 에러 방지

hostname-validation:
  block-numeric-ip: false  # 프록시 IP 다이렉트 접속 차단 방지
\\\

## 🎮 인게임 제어 (GUI 관리자 메뉴)
복잡하게 명령어를 외울 필요 없이, 인게임에서 GUI로 모든 방어막을 껐다 켤 수 있습니다.

- **명령어**: /l7def gui (권한: OP)
- 18종 이상의 방어막(지도 캡챠, 리소스팩 캡챠, GUI 캡챠, 움직임 분석 등)을 원클릭으로 끄고 켤 수 있습니다.
- 캡챠 테스트: /l7def test <모듈명> (예: /l7def test map_captcha)

## 🚨 자주 묻는 질문 (FAQ) / 트러블슈팅

**Q. 접속 시 "Ping 기록 없음" 이라는 사유로 차단당해요!**
A. config.yml에서 ping-before-join 기능을 alse로 끄고 서버를 리로드하세요. 프록시 서버 환경에서는 필수입니다.

**Q. 캡챠 인증을 못해서 강퇴당했는데, 다시 접속하면 바로 밴을 당합니다.**
A. 내부 블랙리스트(메모리 캐시)에 등록되었기 때문입니다. 서버를 재부팅하거나 일정 시간(기본 10분)이 지나면 차단이 해제됩니다. 관리자 닉네임(예: antiYoon_)은 이 블랙리스트를 무시하고 강제로 접속할 수 있도록 내부 Bypass가 적용되어 있습니다.

**Q. 리소스팩 캡챠를 켰더니 유저들이 타임아웃으로 튕겨요.**
A. 클라이언트 설정에서 "서버 리소스팩 사용: 켜기"로 되어 있는지 확인하세요. 플러그인은 아주 가벼운 투명(Empty) 리소스팩(1KB 이하)을 강제 다운로드 시켜서 패킷 통신이 가능한 '진짜 클라이언트'인지 검증합니다.
